KARAHINDIBAG VIMEO EMBED WEBSITE

This version uses Vimeo embeds, not local MP4 files.

Files to upload to GitHub:
- index.html
- style.css
- README.txt

You do NOT need:
- videos folder
- assets folder
- script.js
- videos.js

Vimeo videos included:
1. https://vimeo.com/1199883607
2. https://vimeo.com/1199883605
3. https://vimeo.com/1199885553
4. https://vimeo.com/1199883606

After uploading to GitHub:
1. Commit changes.
2. Wait for Netlify to redeploy.
3. Open https://karahindibag.netlify.app/ in an incognito/private window.
