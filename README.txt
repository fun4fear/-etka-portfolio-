KARAHINDIBAG VIMEO SHOWCASE COMPACT WEBSITE

This version uses one Vimeo Showcase embed.

Showcase:
https://vimeo.com/showcase/12120126

Files to upload to GitHub:
- index.html
- style.css
- README.txt

You do NOT need:
- videos folder
- assets folder
- script.js
- videos.js

How to add/remove videos later:
1. Go to Vimeo.
2. Open the Karahindibag Portfolio Showcase.
3. Add or remove videos there.
4. The website should update from the same Showcase embed.

After uploading to GitHub:
1. Commit changes.
2. Wait for Netlify to redeploy.
3. Open https://karahindibag.netlify.app/ in an incognito/private window.
